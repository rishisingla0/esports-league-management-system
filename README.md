# eSports League Management & Analytics System

A database-focused project for managing competitive eSports leagues, teams, players, tournaments, match results, and player performance.

## Technology Stack

- **Database:** MySQL 8.0
- **Backend:** Java 21, Spring Boot, Maven
- **API Testing:** Postman
- **Version Control:** Git and GitHub

## Planned Features

- Game and organization management
- Team rosters and player transfers
- Tournament registration and scheduling
- Match and map results
- Player performance analytics
- Sponsorship management
- Tournament prize distributions
